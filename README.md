# Subscription Churn Prediction

## Overview

This project develops machine learning models to predict customer subscription churn using customer demographics, service usage behaviour, and engagement patterns.

The objective is to identify customers at risk of cancelling their subscriptions and support proactive retention strategies.

## Dataset

The dataset contains customer subscription information collected across multiple sources and consolidated into a unified analytical dataset.

## Methodology

- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Feature Engineering
- Feature Selection
- Model Training
- Hyperparameter Optimisation
- Model Evaluation

## Experiments

### Experiment 0
Data exploration, preprocessing and baseline model development.

### Experiment 1
Feature selection and importance analysis.

### Experiment 2
Training and evaluation of predictive models.

### Experiment 3
Hyperparameter tuning and optimisation.

### Experiment 4
Final model selection and business recommendations.

## Technologies

- Python

## Business Impact

The solution enables organisations to identify high-risk customers early and improve retention through targeted intervention strategies.
